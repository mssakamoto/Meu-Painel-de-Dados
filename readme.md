💻Atividade Agenda 09 : Meu painel de dados 

🧑🏻‍💻Este programa tem como objetivo cadastrar as tarefas de rotina. Inicialmente são solictados dados de entrada como nome, cidade e a quantidade de tarefas a ser executada. As tarefas a serem executadas são descritas em ordem sequencial. Ao final do programa, mostra-se a lista de tarefas cadastradas e a mensagem relacionada à quantidade de tarefas informada

Liguagem usada: PYTHON
